# Quick Start Guide

## Immediate Setup (2 minutes)

### Step 1: Get Groq API Key (Optional)
Visit: https://console.groq.com
- Sign up (free)
- Create API key
- Copy the key

### Step 2: Configure
Open `config.js` and paste your API key:
```javascript
GROQ_API_KEY: 'your_actual_key_here'
```

### Step 3: Run
Already running on http://localhost:8080

### Step 4: Play!
Click the screen to start playing.

## Without API Key
The game works fine without an API key! You'll just get pre-written horror narration instead of AI-generated content.

## Controls Quick Reference
- **WASD** - Move
- **Shift** - Sprint
- **F** - Toggle flashlight
- **H** - Get hint
- **E** - Open doors
- **C** - Crouch

## Objective
1. Collect all 5 golden keys
2. Find the exit door
3. Escape alive!

## Tips
- Save battery by turning off flashlight
- Monsters chase you when they see you
- Low sanity = hallucinations
- Crouch to move quieter

Have fun! 🎮👻
