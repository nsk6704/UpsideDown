# Crystal Core Adventure 🌴✨

An immersive, multi-level VR-ready treasure hunt game built with Three.js. Explore a lush jungle, discover secret cave entrances, and descend into the glowing Crystal Core.

## 🎮 Features

- **Two Distinct Worlds**: 
  - **The Jungle**: A vibrant, sun-drenched surface world.
  - **The Crystal Core**: A bright, magical subterranean world lit by an internal sun.
- **Dynamic Weather**: Rain in the jungle and magical crystal dust in the core.
- **AI Guide**: A helpful spirit guide that provides context-aware hints.
- **Interactive Map**: A circular explorer's map that rotates with you.
- **Compass**: Real-time orientation to help you navigate.
- **Custom Audio**: Support for custom ambient sounds and sound effects.

## 🕹️ Controls

- **WASD**: Move
- **Shift**: Sprint
- **M**: Toggle Map (Look around to orient)
- **T**: Talk to Guide (Get hints)
- **L**: Debug Teleport (Switch between Jungle and Core)
- **Esc**: Pause Menu / Show Cursor
